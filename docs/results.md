# Reproducible Results

These are functional results for Volt 0.1.4, recorded on 27 July 2026. They
demonstrate deterministic behavior on synthetic fixtures; they are not
investment performance or a benchmark claim.

## Test suite

```bash
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
```

Result:

| Suite | Tests | Result |
| --- | ---: | --- |
| compiler and candidate grammar | 12 | passed |
| contract, canonical, market, runtime, and graph logic | 13 | passed |
| scenario simulation | 3 | passed |
| graph and scenario command adapters | 3 | passed |
| teaching-pricer example checks | 6 | passed |
| **Total** | **37** | **passed** |

The tests cover, among other things, order-independent canonicalization,
terminal-payoff agreement, exercise and assignment authority, deterministic
replay hashes, executable-side quote semantics, graph equivalence hashes,
candidate branching, fill failure on missing quote sides, and cash/underlying
attribution.

## `risk`

Command:

```bash
cargo run -q --example risk -- \
  --record --ticks 1 --interval-ms 0 --seed 28695
```

The first deterministic frame constructed four exact SIMX contracts and a
canonical cash-settled European *iron condor*. The terminal projection had
four payoff knots. The simulated spot was 98.04, teaching-model volatility was
24.88%, and the displayed expiration bounds were +$190.80 and -$309.20.

The [28-frame recording](markup/README.md) is generated by the same executable.
Its Black–Scholes marks and Greeks are educational synthetic values, not
market quotes or investment results.

## `zap`

Command:

```bash
cargo run --quiet --example zap
```

Observed result:

| Experiment | Raw realizations | Exact portfolios | Payoff classes |
| --- | ---: | ---: | ---: |
| two ordered actions | 144 | 73 | 73 |
| six-contract quantities in `[-2, 2]` | 15,625 | 15,625 | 13,321 |

For the ordered experiment, exact canonicalization removed 49.31% of raw
action-sequence representations. For the bounded quantity experiment,
terminal projection merged 14.75% of exact portfolios into an already-seen
payoff class.

The absence of a further payoff reduction in the first row is itself useful:
with only two actions in that small universe, the duplication came from
ordering and offsetting rather than distinct dynamic portfolios sharing a
terminal shape.

## `graph`

Command:

```bash
cargo run --quiet --example graph -- --output /tmp/volt-graphs.jsonl
```

Observed result:

```text
wrote 729 graph samples
```

The first sample used schema `volt.portfolio_graph.v1` and contained 9 nodes
and 18 edges. Its target was
`synthetic_risk_adjusted_terminal_pnl_dollars`, explicitly marked as a
synthetic infrastructure fixture.

Because the enumerated quantity set is `[-1, 0, 1]` over six contracts, the
729 rows are the complete `3^6` bounded quantity space.
