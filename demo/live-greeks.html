VOLT / LIVE RISK

From option quotes to live Greeks

An option quote moves with the stock, the remaining time and the market’s assessment of volatility. Volt turns a changing option chain into implied volatilities, contract sensitivities and a common view of portfolio risk.

Browser viewer

Follow the volatility surface and an expiry smile alongside portfolio Greeks. Stock and volatility scenarios show the book’s response to a specified market move.

Run the browser viewer
cargo run --release -p volt-compute \
  --features live-risk --bin live_option_risk
# Open http://127.0.0.1:8088

Terminal monitor

A compact, top-style display reads the same native snapshots. It keeps signed positions, per-unit contract Greeks and scenario changes aligned in one updating screen.

Run the terminal monitor
# Start the browser service, then in another terminal:
cargo run --example live_risk_top -- \
  --address 127.0.0.1:8088

Reading the example

The recorded book sells ten calls and ten puts at strike 100, with approximately 60 days remaining and a multiplier of 100. This short straddle has negative gamma and vega, together with positive calendar theta. As the stock moves away from the strike, its delta changes.

The option value is the signed mark of those positions. Premium cash, financing and subsequent trades enter a complete trading ledger. The scenario amounts show changes in option value under the stated stock or volatility shock.

Calculation and coverage

The replay supplies synthetic bid/ask quotes and a stock mark. Volt solves for implied volatility, interpolates total variance, calculates Greeks and reprices the scenarios. Both presentations consume those calculated results.

The current valuation engine covers European options with deterministic interest rates and a continuous dividend yield. American and Bermudan contract schedules already exist in Volt’s contract model; early-exercise pricing, dated cash dividends and their model-consistent Greeks are the next coverage milestone for a broad US stock and ETF application.

Try a complete snapshot

A bounded run calculates a single synthetic chain and writes the result for inspection or terminal replay:

cargo run --release -p volt-compute --features live-risk \
  --bin live_option_risk -- --once --output /tmp/volt-live-risk.json
cargo run --example live_risk_top -- \
  --input /tmp/volt-live-risk.json --ticks 1 --no-color
